# 🚀 CodeArena

CodeArena is a browser-based online compiler that allows users to write, compile, and execute code directly from the browser.

## ✨ Features

* Execute code instantly
* Multi-language support
* Custom input support
* Real-time output
* Responsive UI
* Dark mode
* Monaco Editor integration

## 💻 Supported Languages

* C++
* Java
* JavaScript
* Python

## 🛠 Tech Stack

### Frontend

* React
* Vite
* Axios
* Monaco Editor

### Backend

* Node.js
* Express.js

### Execution

* Judge0 API

## 🏗 Project Architecture

Frontend
↓
Backend
↓
Judge0 API
↓
Output

## ⚙ Installation

Clone:

```bash
git clone https://github.com/akashsingh77-ux/CodeArena.git
cd CodeArena
```

Backend:

```bash
cd backend
npm install
npm run dev
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

## 🚀 Deployment

Frontend → Vercel
Backend → Render
